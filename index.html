How to use this dashboard

Option A — Connect a live Google Sheet

  1. Open your LinkedIn Ads export sheet in Google Sheets.
  2. Go to Extensions > Apps Script, delete any starter code.
  3. Paste in the provided apps_script_code.gs file contents. Update SHEET_NAME if your tab isn't named "Sheet1".
  4. Click Deploy > New deployment → type Web app.
  5. Set "Execute as" to Me, "Who has access" to Anyone. Deploy and authorize.
  6. Copy the URL ending in /exec, paste it into the box above, click Connect.

Option B — Upload a CSV

  1. Export your campaign report from LinkedIn Campaign Manager (or Windsor.ai / similar) as CSV.
  2. Make sure it includes these columns: Start Date (in UTC), Campaign Name, Ad Set Name, Clicks, Total Spent, Impressions, Leads, Conversions.
  3. Click Upload CSV above and select the file.
  4. The dashboard loads instantly — no sheet connection needed, but it won't auto-refresh with new data.

Once connected, this dashboard shows spend, CTR, CPC, leads, and conversions by campaign and ad set, with sortable tables and date-range filters. Nothing is uploaded to any server — the CSV is parsed entirely in your browser, and the sheet connection talks directly to your own Google Apps Script endpoint.
